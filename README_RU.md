## О программе

* Эта программа позволяет пропускать диалоги в игре Genshin Impact. Она написана на языке программирования Rust.
* Работает похоже на автокликер, но пропускает диалоги по особому, осторожному шаблону.
* Последовательность такая: Алгоритм -> Клавиатура -> Игра.

* Все тайминги случайные, поэтому ввод выглядит естественно и при этом остаётся быстрым:
  * 80–140 мс пауза между циклами;
  * 20–40 мс пауза между клавишами;
  * каждая клавиша удерживается 25–55 мс — как при живом нажатии.
* GDS не читает и не меняет память игры и ничего в неё не внедряет — он только отправляет нажатия клавиш, как обычная клавиатура.

## 🛠️ Установка

1. Перейдите в раздел [Releases](https://github.com/ProstoInside/Genshin-Dialogs-Skipper/releases) и скачайте последнюю версию файла gds.exe.

2. После скачивания можно переместить исполняемый файл куда угодно, например на диск C
  * Это необязательно
  * Программу можно запускать прямо из папки загрузок.

3. Запустите программу двойным щелчком и разрешите запуск от имени администратора.
  * Запуск от администратора обязателен, чтобы игра воспринимала нажатия программы как ваши собственные.

4. Далее следуйте инструкции в [INSTRUCTIONS_RU.md](INSTRUCTIONS_RU.md), чтобы правильно настроить программу для комфортной игры.


## 🛠️ Для разработчиков

1. Клонируйте репозиторий:

```bash
git clone https://github.com/ProstoInside/Genshin-Dialogs-Skipper.git
cd Genshin-Dialogs-Skipper
```

   Или скачайте его архивом (**Code → Download ZIP**), распакуйте в любую папку и откройте терминал в этой папке.

### Требования

* Windows 10/11
* [Rust](https://rustup.rs) (stable, MSVC-тулчейн)
* [Visual Studio Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/) с пакетом **«Desktop development with C++»** (в него входит Windows SDK — `rc.exe` нужен, чтобы встроить иконку и манифест)

### Сборка

```bash
cargo build --release
```

Готовая программа появится в `target\release\gds.exe`.

### Другие команды

```bash
# Отладочная сборка с консолью (не запрашивает права администратора)
cargo run

# Запуск тестов
cargo test
```

> [!NOTE]
> Релизная сборка требует права администратора (запрос UAC при запуске).
> Команда `cargo run --release` из терминала без прав администратора завершится ошибкой 740 — запустите терминал от имени администратора или откройте `gds.exe` напрямую.
